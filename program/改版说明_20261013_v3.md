# 物流工具改版说明（2026-10-13，最新版 v3）

## 范围与结果

基于 `e5cf90115d2936436313817970d6305bfd1ab5e9`，在本地分支 `data-review-l3-v3` 完成数据核对呈现和小范围显示/交互修正。采用上传的 v3 任务文件；压缩包里的旧会议材料只作来源参考，执行要求以 v3 为准。没有推送、部署或登录云端保存。

本轮保持三个既有页面和原有布局、筛选、成本下钻、加权比较；手机端没有改版，现有手机样式保留。

## 改动对应要求

### 2.1 数据核对

- 对应最新版第 1 节的锁定口径及微信原话「现在就只有一些数据上的问题要核对」。在登录后的应用详情 Data checks 中补全问题记录、类别与主标签；已映射项目只显示为映射信息项，不再重复报映射前问题。
- Level 3 不在标准列表的主标签按 Overview 的实际原因呈现，并应用到每一条有问题的原始记录。HC.06 保留原值并同时提示「Possibly B.06 – not changed automatically」，不自动改码。
- 保留页面 model（含现存审计映射）的判断口径，保留源记录中的 oneIDM 说明。

### 2.2 简化引用标准

- 对应微信原话「还有要简化引用标准」及最新版第 2.2 节。`Mgmt.` 在显示层展开为 `Management`；编码显示规范化；标准表被截断的名称仍按原样显示。
- 4 个有可靠来源的补全候选只在登录后的应用详情显示为待确认文本，不覆盖标准名、不参与搜索、匹配或打分。编码为 B.06.1.6（P41/P74）、B.06.1.7（P48/P68）、B.06.8.1（P77）、B.06.8.2（P77）。
- Not in catalogue 能力的 tooltip 显示该应用在 LeanIX 的原始能力文字；导入历史用词统一为「LeanIX export」。

### 2.3 减少重复

- 对应微信原话「不要重复使用」及 F9 52:31。应用详情 Source records 只保留 oneIDM 说明、Business capabilities 和 Processes 的原始值；问题标签、候选和 Applied mappings 在 Data checks 中查看，不再重复列出。
- Overview 下钻将维度、应用数、工厂数和已选 BU/Plant 汇总成一行状态；搜索后显示当前数量/原名单数量。应用行只显示业务单元，工厂由组标题表达。
- 移除矩阵左上角重复的应用总数，Not classified 比较弹窗沿用界面列头名称。主 Overview 的 Reset filters 改为 Clear filters。
- 权重临时调整的状态行只显示 “Scores updated.”；“Not saved – resets on reload” 仍保留在权重摘要。

### 2.4 程序问题

- #1：相似度证据标题及来源字段正确转义应用名；加入含 `< & "` 名称的回归检查。
- #2：Not classified 比较弹窗使用一致的标题。
- #3：Based on 提示只统计权重大于 0 的能力/流程维度；两个维度权重都为 0 时不显示误导提示。
- #4：切页或浏览器后退离开全屏时退出全屏。
- #5：Business unit 为空的应用仍可出现在 Landscape 的 Plant 筛选项中，并归为 Not provided。
- #6：单数文案修正为 1 plant、1 pair。
- #7：范围外应用在详情、配对及成本下钻合计中统一显示 Out of scope。
- #8：把低于当前阈值、但已评分确认的配对并入现有 Not similar 诊断组，不新增状态；见下方数字对照。
- #9：`?tab=similarity` 别名改写为 `?tab=opportunities` 时用 replaceState，仅改 `app.js`，未改 `view-route.mjs` 及其测试。
